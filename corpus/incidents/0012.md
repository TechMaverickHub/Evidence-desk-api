# INC-0012: 400 Invalid host header after domain migration (synthetic)

> Synthetic incident written for the EvidenceDesk benchmark. Services, people and events are fictional.

## Summary

After moving to the new domain api.example-shop.test, every request returned 400.

## Impact

Full outage of the public API for 25 minutes.

## Timeline (UTC)

- 07:00 DNS switched to the new domain.
- 07:01 All requests answered with 400 'Invalid host header'.
- 07:25 Config change deployed.

## Root cause

`TrustedHostMiddleware` was configured with `allowed_hosts` containing only the old domain.

## Resolution

Added the new domain to `allowed_hosts` and made the list an environment setting.

## Follow-ups

- Include a request through the new hostname in the migration checklist.
