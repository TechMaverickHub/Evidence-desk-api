# INC-0017: 500 errors after the Pydantic v2 upgrade (synthetic)

> Synthetic incident written for the EvidenceDesk benchmark. Services, people and events are fictional.

## Summary

After upgrading to Pydantic v2, endpoints returning ORM objects failed with 500.

## Impact

Account pages failed for 40 minutes after the upgrade release.

## Timeline (UTC)

- 14:00 Release with Pydantic v2.
- 14:01 Errors: 'Input should be a valid dictionary or instance of AccountOut'.
- 14:40 Fix deployed.

## Root cause

The response models still used the v1 `class Config: orm_mode = True`. In Pydantic v2 the setting is `from_attributes`, so models no longer read attributes from ORM objects.

## Resolution

Replaced with `model_config = ConfigDict(from_attributes=True)`.

- Run the full test suite with deprecation warnings as errors before upgrades.
