# INC-0020: Users logged out on every request (synthetic)

> Synthetic incident written for the EvidenceDesk benchmark. Services, people and events are fictional.

## Summary

Users of the admin portal were logged out randomly after scaling to several workers.

## Impact

Admin portal unusable for 2 hours.

## Timeline (UTC)

- 15:00 Admin portal scaled from 1 to 4 Uvicorn workers.
- 15:05 Reports of being logged out after each click.
- 17:00 Fix deployed.

## Root cause

`SessionMiddleware` was given a `secret_key` generated randomly at startup. Each worker had a different key, so a session cookie signed by one worker was rejected by the others.

## Resolution

The secret key is read from the secret store, identical for every worker.

## Follow-ups

- Fail startup if security secrets are missing instead of generating them.
