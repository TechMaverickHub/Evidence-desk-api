# INC-0003: Swagger UI blank when served under /api prefix (synthetic)

> Synthetic incident written for the EvidenceDesk benchmark. Services, people and events are fictional.

## Summary

The interactive API docs at `/api/docs` loaded an empty page after the gateway started stripping the `/api` path prefix.

## Impact

Internal developers could not use the docs for one day; no customer impact.

## Timeline (UTC)

- Day 1 10:00 Gateway route changed to strip `/api` before forwarding.
- Day 1 11:30 Docs page shows 'Failed to load API definition'.
- Day 2 09:40 Fix deployed.

## Root cause

The browser requested `/openapi.json` instead of `/api/openapi.json` because the application did not know it was mounted under a prefix. `root_path` was not set.

## Resolution

Started Uvicorn with `--root-path /api` so FastAPI generates the OpenAPI URL and server list with the prefix.

## Follow-ups

- Document the `root_path` setting in the service template.
