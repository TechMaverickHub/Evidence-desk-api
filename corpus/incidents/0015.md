# INC-0015: Large file uploads failing with 413 (synthetic)

> Synthetic incident written for the EvidenceDesk benchmark. Services, people and events are fictional.

## Summary

Uploads of PDF contracts over 1 MB failed with 413 Request Entity Too Large.

## Impact

Customers could not upload contracts for 1 day.

## Timeline (UTC)

- Day 1 New ingress controller deployed.
- Day 1 Upload failures reported; the application logs show no requests.
- Day 2 Ingress body-size limit raised.

## Root cause

The new ingress had a default request body limit of 1 MB. Requests were rejected before reaching the `UploadFile` endpoint, so application logs and metrics showed nothing.

## Resolution

Raised the ingress body limit to 25 MB for the upload route only.

## Follow-ups

- Synthetic upload check for files above 1 MB after ingress changes.
