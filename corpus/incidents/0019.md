# INC-0019: Server-sent events delivered late (synthetic)

> Synthetic incident written for the EvidenceDesk benchmark. Services, people and events are fictional.

## Summary

Dashboard live updates, sent as a streaming response, arrived in bursts every few seconds instead of immediately.

## Impact

Degraded live view for operators for a week; no data loss.

## Timeline (UTC)

- Week 1 Dashboard traffic moved behind a new reverse proxy in front of Uvicorn.
- Week 2 Operators report delayed live updates.
- Week 2 Response buffering disabled for the events route on the proxy.

## Root cause

The new reverse proxy buffered upstream responses by default. It collected the small event messages from the streaming response and forwarded them only when its buffer filled or the stream paused, so events reached browsers in bursts. Requests sent directly to Uvicorn were not delayed.

## Resolution

Turned off response buffering on the proxy for the live-events route, so each event is forwarded as soon as the application sends it.

## Follow-ups

- Test streaming endpoints through every proxy and middleware layer that sits in front of them.
