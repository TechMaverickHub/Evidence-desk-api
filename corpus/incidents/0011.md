# INC-0011: CORS failures after enabling credentials (synthetic)

> Synthetic incident written for the EvidenceDesk benchmark. Services, people and events are fictional.

## Summary

The web dashboard could not call the API after we enabled cookie-based auth.

## Impact

Dashboard unusable for 1 hour after release.

## Timeline (UTC)

- 11:00 Release sets `allow_credentials=True` on `CORSMiddleware`.
- 11:02 Browser console: credentialed request rejected by CORS policy.
- 12:00 Fix deployed.

## Root cause

`allow_origins` was `['*']`. Browsers do not accept a wildcard origin for credentialed requests, so preflight responses were rejected.

## Resolution

`allow_origins` now lists the dashboard origins explicitly.

## Follow-ups

- CORS configuration reviewed in every release that touches auth.
